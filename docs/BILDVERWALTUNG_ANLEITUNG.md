# 📸 GartenMeister Bildverwaltung - Benutzeranleitung

## Übersicht
Die **Bildverwaltung** in GartenMeister ermöglicht es, Gartenfotos zentral zu verwalten, chronologisch zu sortieren und mit Kommentaren zu versehen. Perfekt für die Dokumentation von Pflanzenwachstum, Ernten und Gartenprojekten.

## 🚀 Schnellstart

### 1. **Bildersammlung öffnen**
```
📍 Navigation: Seitenleiste → "Bildersammlung" klicken
```
- Oder über das **Kamera-Symbol** in der Hauptnavigation
- Shortcut: `Strg + G` (Gallery)

### 2. **Erstes Bild hochladen**
```
📸 Upload: "Bilder hochladen" Button → Dateien auswählen → Metadaten eingeben → Upload
```

### 3. **Kategorien verstehen**
- **🌱 Wachstum**: Pflanzentwicklung über Zeit
- **🥕 Ernte**: Erträge und Ernteresultate  
- **🐛 Schädlinge**: Probleme und Behandlungen
- **🏡 Allgemein**: Sonstige Gartenaufnahmen

## 📋 Detaillierte Anleitungen

### 🔄 **Bilder hochladen**

#### **Einzelner Upload:**
1. **"Bilder hochladen"** Button klicken
2. **Datei auswählen** (JPG, PNG, GIF, WebP, BMP, TIFF, SVG)
3. **Metadaten eingeben:**
   ```
   ✏️ Titel: "Tomatenwachstum Woche 4"
   📝 Beschreibung: "Erste Blüten sind sichtbar"
   🏷️ Kategorie: "Wachstum"
   🌿 Beet: "Beet 1" (optional)
   📌 Tags: "Tomaten, Woche4, Gewächshaus"
   ```
4. **"Hochladen"** klicken

#### **Batch-Upload (mehrere Bilder):**
1. **"Mehrere Bilder auswählen"** aktivieren
2. **Alle gewünschten Dateien** markieren (Strg+Click)
3. **Gemeinsame Metadaten** eingeben
4. **Upload starten** - jedes Bild wird einzeln verarbeitet

#### **Drag & Drop Upload:**
```
💡 Tipp: Bilder einfach in das Upload-Feld ziehen!
```
- Dateien direkt in den **Upload-Bereich ziehen**
- **Automatische Erkennung** mehrerer Dateien
- **Batch-Metadaten** Dialog öffnet sich

### 🗂️ **Navigation & Ansichten**

#### **Kategorien-Tabs:**
```
📁 Alle Bilder     📈 Wachstum     🥕 Ernte     🐛 Schädlinge     🏡 Allgemein
```

#### **Ansichtsmodi:**
- **🔲 Grid-Modus**: Übersichtliche Kachel-Ansicht
- **📋 Listen-Modus**: Detaillierte Tabellenansicht
- **Umschalten**: Buttons oben rechts

#### **Sortierung:**
```
🔤 Nach: Aufnahmedatum | Upload-Datum | Titel | Beliebtheit
📊 Reihenfolge: Neueste zuerst ↓ | Älteste zuerst ↑
```

### 🔍 **Suche & Filter**

#### **Schnellsuche:**
```
🔍 Suchfeld: Titel, Beschreibung, Tags durchsuchen
```
- **Live-Suche** während der Eingabe
- **Mehrere Begriffe** durch Leerzeichen trennen
- **Tags finden**: Einfach den Tag-Namen eingeben

#### **Erweiterte Filter:**
```
🏷️ Kategorie: Wachstum, Ernte, Schädlinge, Allgemein
🌿 Beet: Spezifisches Beet auswählen
📅 Datum: Von-Bis Zeitraum
👤 Autor: Nach Upload-Person filtern
⭐ Nur Favoriten: Markierte Bilder anzeigen
```

#### **Filter-Kombinationen:**
```
Beispiel 1: Kategorie "Wachstum" + Beet "Tomatenhaus" + Juli 2025
Beispiel 2: Tag "Schädlinge" + Autor "Max" + Favoriten
```

### 💬 **Kommentare & Interaktion**

#### **Kommentar hinzufügen:**
1. **Bild anklicken** → Detailansicht öffnet sich
2. **Kommentar-Bereich** nach unten scrollen
3. **Text eingeben** im Eingabefeld
4. **"Kommentar hinzufügen"** klicken

#### **Kommentare verwalten:**
```
✏️ Bearbeiten: Stift-Symbol neben eigenem Kommentar
🗑️ Löschen: Papierkorb-Symbol (nur eigene Kommentare)
```

#### **Bewertungen geben:**
```
⭐ Sterne-System: 1-5 Sterne vergeben
📊 Durchschnitt: Wird automatisch berechnet
```

### ⭐ **Favoriten & Bookmarks**

#### **Favorit markieren:**
```
❤️ Herz-Symbol: In Detailansicht oder Grid-Ansicht klicken
```
- **Toggle-Funktion**: Ein-/Ausschalten
- **Favoriten-Filter**: Nur markierte Bilder anzeigen
- **Schnellzugriff**: Wichtige Bilder leicht finden

#### **Favoriten-Übersicht:**
```
📍 Navigation: Filter → "Nur Favoriten" aktivieren
```

### 📊 **Statistiken & Übersicht**

#### **Übersichtskarten:**
```
📸 Gesamte Sammlung: Anzahl aller Bilder
📤 Letzte Uploads: Diese Woche hochgeladen
👥 Mitwirkende: Anzahl aktiver Fotografen
```

#### **Detailstatistiken:**
- **Upload-Trends**: Monatliche Entwicklung
- **Kategorie-Verteilung**: Welche Bildtypen am häufigsten
- **Top-Fotografen**: Wer uploaded am meisten
- **Beliebteste Bilder**: Meist angesehene/kommentierte

### 🔧 **Bild-Verwaltung**

#### **Metadaten bearbeiten:**
1. **Bild öffnen** → Detailansicht
2. **"Bearbeiten"** Button (Stift-Symbol)
3. **Felder ändern:**
   ```
   📝 Titel/Beschreibung anpassen
   🏷️ Kategorie wechseln
   📌 Tags hinzufügen/entfernen
   🌿 Beet neu zuordnen
   📍 Standort korrigieren
   ```
4. **"Speichern"** klicken

#### **Bilder löschen:**
```
⚠️ Vorsicht: Löschen ist endgültig!
```
1. **Bild auswählen** → Detailansicht
2. **"Löschen"** Button (Papierkorb-Symbol)
3. **Bestätigung** erforderlich
4. **Endgültiges Entfernen** aus allen Ansichten

#### **Archivieren:**
```
📦 Archiv: Bilder ausblenden ohne zu löschen
```
- **Archiv-Button** in Detailansicht
- **Ausgeblendete Bilder** in separater Ansicht
- **Wiederherstellung** jederzeit möglich

## 🎨 **Anwendungsfälle & Workflows**

### 🌱 **Pflanzenwachstum dokumentieren**

#### **Wöchentlicher Workflow:**
```
📅 Jeden Sonntag:
1. 📸 Fotos von allen Beeten machen
2. 📤 Batch-Upload mit Metadaten:
   - Titel: "Tomaten - Woche 12"
   - Kategorie: "Wachstum"
   - Tags: "woche12, gewächshaus, juli"
3. 💬 Kommentare zu Veränderungen hinzufügen
4. ⭐ Besondere Entwicklungen als Favoriten markieren
```

#### **Zeitraffer-Vorbereitung:**
```
🎬 Für Zeitraffer-Videos:
- Gleicher Aufnahmewinkel
- Konsistente Beleuchtung
- Wöchentliche Intervalle
- Einheitliche Metadaten
```

### 🥕 **Ernte-Dokumentation**

#### **Ernte-Session:**
```
📸 Pro Erntetag:
1. Vorher-Bild: Reife Pflanzen im Beet
2. Prozess-Bild: Während der Ernte
3. Nachher-Bild: Geerntete Produkte
4. Detail-Bilder: Besonders schöne Exemplare

💾 Metadaten:
- Kategorie: "Ernte"
- Tags: "karrotten, juli, rekordernte"
- Beschreibung: "3.2kg Karotten, größte 28cm"
```

### 🐛 **Schädlings-Monitoring**

#### **Problem-Dokumentation:**
```
🔍 Bei Problemen:
1. 📸 Übersichtsbild: Betroffene Pflanze/Bereich
2. 📸 Detail-Bild: Nahaufnahme des Problems
3. 📸 Vergleichsbild: Gesunde Pflanze daneben

📝 Metadaten:
- Kategorie: "Schädlinge"
- Tags: "blattläuse, rosen, behandlung"
- Beschreibung: "Starker Befall, Neem eingeleitet"

💬 Kommentare für Behandlungsverlauf
```

### 🏡 **Garten-Portfolio**

#### **Jahresüberblick erstellen:**
```
📂 Portfolio-Sammlung:
1. ⭐ Beste Bilder als Favoriten markieren
2. 🔍 Filter: Favoriten + aktuelles Jahr
3. 📊 Export für PDF-Report verwenden
4. 💬 Kommentare mit Lessons Learned
```

## 🛠️ **Problembehandlung**

### ❌ **Upload-Probleme**

#### **Datei wird nicht akzeptiert:**
```
🔍 Prüfen:
- ✅ Dateigröße < 50MB
- ✅ Format: JPG, PNG, GIF, WebP, BMP, TIFF, SVG
- ✅ Datei nicht beschädigt
- ✅ Speicherplatz verfügbar
```

#### **Upload bricht ab:**
```
🔄 Lösungsschritte:
1. 📶 Internetverbindung prüfen
2. 🔄 Seite neu laden
3. 💾 Speicherplatz prüfen
4. 🖥️ App neu starten
```

### 🔍 **Suche funktioniert nicht**

#### **Keine Ergebnisse:**
```
🔧 Debugging:
- 🧹 Suchbegriff vereinfachen
- 🔍 Filter zurücksetzen
- 📅 Datum-Range erweitern
- 🏷️ Andere Kategorie versuchen
```

#### **Langsame Suche:**
```
⚡ Performance:
- 💾 Browser-Cache leeren
- 🔄 App neu starten
- 📊 Große Sammlungen: Paging aktiviert
```

### 💬 **Kommentare verschwunden**

#### **Sync-Probleme:**
```
🔄 Wiederherstellung:
1. 📱 Mobile/Desktop synchronisieren
2. 💾 Cloud-Sync Status prüfen
3. 🔄 Manuelle Synchronisation starten
4. 📞 Support kontaktieren
```
