# GartenMeister Studio - Benutzerhandbuch

## 🌿 Willkommen bei GartenMeister Studio

GartenMeister Studio ist eine umfassende Desktop-Anwendung für das Management Ihres Kräutergartens. Diese Software hilft Ihnen dabei, Ihre Beete zu planen, Ernten zu verfolgen, Bilder zu sammeln und professionelle Berichte zu erstellen.

## Installation und Setup

### System-Anforderungen
- Windows 10 oder höher
- Mindestens 4 GB RAM
- 1 GB freier Festplattenspeicher
- Internetverbindung für Wetter- und Cloud-Funktionen

### Installation
1. Laden Sie `GartenMeister-Setup.exe` herunter
2. Führen Sie die Setup-Datei als Administrator aus
3. Folgen Sie den Installationsanweisungen
4. Starten Sie GartenMeister über das Desktop-Symbol oder Startmenü

### Erste Konfiguration
1. Öffnen Sie **Einstellungen** über das Menü oder die Seitenleiste
2. Konfigurieren Sie Ihren Cloud-Speicher (optional)
3. Richten Sie die Wetterstation ein
4. Verbinden Sie Ihren Google-Kalender (optional)

---

## Erste Schritte

### 1. Erstes Beet anlegen
1. Klicken Sie auf **"Neues Beet"** in der Hauptübersicht
2. Geben Sie einen Namen ein (z.B. "Hauptbeet", "Küchenkräuter")
3. Wählen Sie einen Typ:
   - **Hauptbeet**: Für reguläre Kräuterkulturen
   - **Versuchsbeet**: Für Experimente und Tests
4. Speichern Sie das Beet

### 2. Segmente hinzufügen
1. Öffnen Sie Ihr neues Beet
2. Klicken Sie auf **"Segment hinzufügen"**
3. Wählen Sie eine Kräutersorte aus der Liste
4. Geben Sie die gewünschte Größe an
5. Speichern Sie das Segment

### 3. Übersicht betrachten
- Die Hauptübersicht zeigt alle Ihre Beete visuell an
- Beete werden proportional zur Größe dargestellt
- Verschiedene Kräuter haben unterschiedliche Farben

## Beete verwalten

### Beet-Typen

#### Hauptbeete
- Für reguläre, dauerhafte Kräuterkulturen
- Standardgröße und -layout
- Optimiert für Produktionsanbau

#### Versuchsbeete
- Für Experimente und Tests
- Flexible Segmentaufteilung
- Ideal für neue Sorten oder Anbaumethoden

### Beet bearbeiten
1. Klicken Sie auf ein Beet in der Übersicht
2. Wählen Sie **"Bearbeiten"**
3. Ändern Sie Name, Typ oder andere Eigenschaften
4. Speichern Sie die Änderungen

### Beet löschen
1. Öffnen Sie das zu löschende Beet
2. Klicken Sie auf **"Löschen"**
3. Bestätigen Sie die Löschung
⚠️ **Achtung**: Alle Segmente und Ernteprotokolle gehen verloren!

## Kräuter und Segmente

### Verfügbare Kräutersorten
GartenMeister enthält eine umfangreiche Datenbank mit Kräutersorten:
- Basilikum (verschiedene Sorten)
- Rosmarin, Thymian, Oregano
- Minze-Variationen
- Petersilie, Schnittlauch, Dill
- Salbei, Lavendel
- Exotische Kräuter wie Zitronengras

### Neue Kräutersorte hinzufügen
1. Gehen Sie zu **Kräuter** in der Seitenleiste
2. Klicken Sie auf **"Neue Sorte"**
3. Geben Sie Namen und Eigenschaften ein
4. Speichern Sie die neue Sorte

### Segment-Management
- **Hinzufügen**: Neue Segmente zu bestehenden Beeten
- **Bearbeiten**: Kräutersorte oder Größe ändern
- **Löschen**: Einzelne Segmente entfernen
- **Neu anpflanzen**: Segmente für neue Saison vorbereiten

## Ernteverfolgung

### Ernte starten
1. Klicken Sie auf **"Ernte starten"** in der Hauptübersicht
2. Wählen Sie die Segmente aus, die Sie ernten möchten
3. Geben Sie die Erntemengen ein
4. Fügen Sie optional Notizen hinzu
5. Speichern Sie die Ernte

### Ernteprotokoll
- Alle Ernten werden automatisch protokolliert
- Datum, Zeit und Menge werden gespeichert
- Notizen für besondere Beobachtungen
- Exportierbar in PDF-Berichten

### Statistiken
- Ernteerträge pro Segment
- Saisonale Vergleiche
- Produktivitätsanalysen
- Verfügbar in der Berichts-Sektion

## Bildersammlung

### Bilder hinzufügen
1. Gehen Sie zur **Galerie**
2. Klicken Sie auf **"Bilder hinzufügen"**
3. Wählen Sie Dateien von Ihrem Computer
4. Fügen Sie Beschreibungen und Tags hinzu
5. Speichern Sie die Bilder

### Organisation
- **Kategorien**: Ordnen Sie Bilder thematisch
- **Tags**: Verschlagworten für einfache Suche
- **Datum**: Automatische Zeitstempel
- **Kommentare**: Notizen zu jedem Bild

### Batch-Import
1. Wählen Sie **"Batch-Import"**
2. Selektieren Sie einen Ordner mit Bildern
3. GartenMeister importiert alle unterstützten Formate
4. Bearbeiten Sie Metadaten nach dem Import

## PDF-Export

### Gartenübersicht exportieren
1. Klicken Sie auf **"PDF Export"** in der Hauptübersicht
2. Wählen Sie die zu exportierenden Beete
3. Konfigurieren Sie das Layout
4. Klicken Sie auf **"PDF erstellen"**
5. Das PDF wird automatisch geöffnet

### Berichts-Optionen
- **Vollständige Übersicht**: Alle Beete und Segmente
- **Einzelne Beete**: Nur spezifische Beete
- **Ernteprotokoll**: Ernte-Statistiken und -historie
- **Bilder-Report**: Sammlung mit Garten-Fotos

### Export-Ordner
- Alle PDFs werden in einem zentralen Export-Ordner gespeichert
- Zugriff über **"Export-Ordner öffnen"**
- Organisiert nach Datum und Typ

## Cloud-Synchronisation

### Cloud-Speicher einrichten
1. Gehen Sie zu **Einstellungen**
2. Klicken Sie auf **"Cloud-Ordner auswählen"**
3. Wählen Sie Ihren Cloud-Speicher-Ordner:
   - OneDrive
   - Google Drive
   - Dropbox
   - NAS-Laufwerk
4. Speichern Sie die Einstellung

### Automatische Synchronisation
- Daten werden automatisch synchronisiert
- Backup bei jeder Änderung
- Zugriff von mehreren Geräten
- Schutz vor Datenverlust

### NAS-Integration
Für erweiterte Nutzer:
- Synology, QNAP und andere NAS-Systeme
- Lokale Netzwerk-Synchronisation
- Erweiterte Backup-Strategien

## Fehlerbehebung

### Häufige Probleme

#### App startet nicht
1. Prüfen Sie die Windows-Ereignisanzeige
2. Führen Sie GartenMeister als Administrator aus
3. Deaktivieren Sie Antivirus-Software temporär
4. Neuinstallation der Anwendung

#### Daten werden nicht gespeichert
1. Überprüfen Sie Berechtigungen im Datenordner
2. Prüfen Sie verfügbaren Speicherplatz
3. Deaktivieren Sie Cloud-Sync temporär
4. Führen Sie eine Datenbank-Reparatur durch

#### Cloud-Sync funktioniert nicht
1. Überprüfen Sie die Internetverbindung
2. Kontrollieren Sie Cloud-Speicher-Berechtigungen
3. Wählen Sie den Cloud-Ordner erneut aus
4. Starten Sie die App neu

#### PDF-Export schlägt fehl
1. Schließen Sie andere PDF-Anwendungen
2. Überprüfen Sie Berechtigungen im Export-Ordner
3. Reduzieren Sie die Anzahl der zu exportierenden Beete
4. Verwenden Sie die Fallback-Export-Option

### Support
Bei weiteren Problemen:
1. Sammeln Sie Fehlermeldungen und Screenshots
2. Notieren Sie die Schritte, die zum Fehler führten
3. Überprüfen Sie die Log-Dateien im Anwendungsordner
4. Konsultieren Sie die Online-Dokumentation

### Log-Dateien
Speicherorte für Diagnose:
- `%APPDATA%\GartenMeister\logs\`
- `%APPDATA%\GartenMeister\data\`
- Windows-Ereignisprotokoll

## Anhang

### Tastaturkürzel
- **Strg + N**: Neues Beet
- **Strg + S**: Speichern
- **Strg + E**: PDF exportieren
- **F5**: Ansicht aktualisieren
- **F11**: Vollbildmodus

### Unterstützte Dateiformate
- **Bilder**: JPG, PNG, GIF, BMP, TIFF
- **Export**: PDF
- **Import**: CSV (für Kräuterdaten)

### System-Ordner
- **Daten**: `%APPDATA%\GartenMeister\data\`
- **Bilder**: `%APPDATA%\GartenMeister\images\`
- **Export**: `%USERPROFILE%\Documents\GartenMeister\Export\`
- **Logs**: `%APPDATA%\GartenMeister\logs\`
